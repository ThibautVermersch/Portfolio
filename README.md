# Portfolio Web — Vermersch Thibaut

Portfolio interactif développé en pur HTML, CSS et JavaScript vanilla, conçu autour d'une identité visuelle inspirée de l'univers audio et des platines vinyles.

Ce projet me permet de présenter mes compétences, mes projets académiques et personnels ainsi que mon parcours dans le développement web et logiciel.

---

## Fonctionnalités

- **Interface orbitale interactive :** Navigation originale inspirée d'un vinyle avec boutons satellites et micro-interactions.
- **Thème dynamique :** Bascule entre mode sombre et clair avec persistance du choix.
- **Sélecteur de langue :** Gestion du contenu en français et en anglais.
- **Consultation de CV :** Boutons d'aperçu direct dans le navigateur et de téléchargement automatique du fichier PDF.
- **Design Responsive :** Adaptation fluide sur mobile, tablette et grand écran (Flexbox & CSS Grid).

---

## Stack technique

- **HTML5 :** Structure sémantique et accessibilité.
- **CSS3 :** Variables CSS, animations, Flexbox, transformations trigonométriques pour le menu orbital.
- **JavaScript (ES6+) :** Gestion du lecteur audio, bascule du thème, interactions DOM.
- **Design :** Prototypage et maquettage sur Figma.
